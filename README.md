# Moments of Joy

## Project Overview
Moments of Joy is a simple gratitude journal web app. It helps users record small happy moments from their daily lives and revisit them later. The goal is to encourage gratitude, self-reflection, and appreciation of everyday life.

## Main Features
- **Daily Joys Notes:** Write and save daily joyful moments.
- **List of Your Joys:** View, sort, favorite, and delete saved notes.
- **Saved Memories:** Generate a random memory from previously saved joys.

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage
