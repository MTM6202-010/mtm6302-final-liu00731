## Clarification Questions and Responses

### 1. Word Limit
The client confirmed that the 90–120 word limit should be strictly enforced.

**Decision:** Notes under 90 words cannot be saved. Notes over 120 words are prevented.

### 2. Bulk Deletion
The client gave the developer flexibility and suggested individual checkboxes and a Select All option.

**Decision:** Each joy card will have a checkbox. Users can select individual entries or select all, then delete selected entries after confirmation.

### 3. Random Memory
The client confirmed that random memories should include all saved entries, including non-favorites.

**Decision:** The random memory feature will select from the complete list of saved joys.
